# Исходные данные H1

Полная учебная база лежит в общих артефактах предзащиты.

| Файл | Где лежит | Что это |
|---|---|---|
| `fridge_lab.sqlite` | `Предзащита_НИР/Общие_артефакты/данные/` | 200 семей, семя генератора 42, официальный прогон H1 |
| `каталог/` | эта папка | справочник продуктов генератора |
| `метрики/forecast_v2_households.csv` | эта папка | Recall@10 и PR-AUC по каждой семье |
| `метрики/forecast_v2_summary.csv` | эта папка | средние по вариантам |
| `метрики/forecast_v2_history_length.csv` | эта папка | короткая история, 40 семей |

Единица вердикта — семья, не поход. Recall@10 считается внутри семьи по походам, затем усредняется с равным весом.

База H1 — столбец «Личная модель». Вариант — «Общая модель». Столбец «Общая + личная поправка» в критерий «лучше» не входит.
