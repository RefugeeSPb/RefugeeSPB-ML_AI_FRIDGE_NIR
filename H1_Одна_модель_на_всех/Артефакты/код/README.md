# Код H1

Код прогона, которым учили модели и считали вердикт. Команды и ожидаемые числа — в корневом `README.md`.

| Шаг | Файл | Что внутри |
|---|---|---|
| 1 | `1_обучение_валидация_общей.py` | Ранняя остановка общей модели на валидации (`stop_trees`) и `fit_global` |
| 2 | `2_обучение_валидация_личных.py` | `fit_personal`, настройки 150 / 0,05 / 3, семя 42 |
| 3 | `3_сравнение_recall.py` | Recall@10 по семьям и бутстреп; запуск повторяет `eval_h1.py` |

Полный прогон обучения — `personal_h1.py`. База — `Общие_артефакты/данные/fridge_lab.sqlite` (200 семей, семя генератора 42):

```bash
python personal_h1.py
```

Вердикт по уже сохранённым Recall@10 семей, без обучения:

```bash
python eval_h1.py
```

или `python 3_сравнение_recall.py`. Семя бутстрепа **42**, 2000 повторов. Общая лучше, если низ интервала > 0. Пишет `результаты/recall10.csv`.

База — модель только на строках этой семьи. Вариант — одна общая модель. Поправка к общей и похожие семьи в вердикт не входят.
