# Исходные данные H2

Обе базы лежат в общих артефактах после сборки из корневого `README.md`. В git их нет.

| Файл | Где лежит | Что это |
|---|---|---|
| `fridge_lab.sqlite` | `Общие_артефакты/данные/` | 200 семей, семя 42, прогон +0,137 |
| `fridge_lab_v2.sqlite` | `Общие_артефакты/данные/` | 500 семей, семя 43, повтор +0,152 |
| `каталог/` | эта папка | справочник продуктов генератора |
| `метрики/` | эта папка | сохранённые таблицы прогонов |

Кандидаты списка — продукты семьи за последние 60 дней. Момент прогноза — через 3 часа после уже сделанного похода. Метка — продукт в **следующей** корзине.

Правило «обычно берут»: для продукта семьи число походов с ним, делённое на число походов семьи к этому моменту (`pair_visit_share` в `forecast.py`).
