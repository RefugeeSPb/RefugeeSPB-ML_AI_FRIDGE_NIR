# Код H2

Шаги вердикта «общая модель против доли походов». Скоропорт и смена поведения в эти файлы не входят: они остаются в `check_main_v2.py`.

| Шаг | Файл | Что внутри |
|---|---|---|
| 1 | `1_учебная_база.py` | Та же база, что у H1. Кандидаты за 60 дней, прогноз через 3 часа, метка — следующая корзина |
| 2 | `2_общая_модель.py` | Общая модель: Logloss, шаг 0,08, глубина 6, семя 42. На 200 семьях 104 дерева, на 500 — 265 |
| 3 | `3_recall_частоты.py` | Правило `pair_visit_share`. Recall@10 — среднее по походам |
| 4 | `4_сравнение_recall.py` | Прирост модели над правилом. Порог 0,10. Пишет `результаты/recall10.csv` |

Полный прогон, включая другие проверки того же файла, из этой папки. Нужна база `Общие_артефакты/данные/fridge_lab_v2.sqlite`, семя 43:

```bash
python check_main_v2.py
```

Порог `GAIN = 0.10` там не двигается. Учёба до 1 июня 2026, остановка на июне–июле, тест 1 августа — 16 сентября. Семя модели 42.

Вердикт по уже записанным числам, без обучения:

```bash
python 4_сравнение_recall.py
```

База на 200 семей — `Общие_артефакты/данные/fridge_lab.sqlite`. Повтор на 500 семей — `Общие_артефакты/данные/fridge_lab_v2.sqlite`. Сборка обеих — в корневом `README.md`.
