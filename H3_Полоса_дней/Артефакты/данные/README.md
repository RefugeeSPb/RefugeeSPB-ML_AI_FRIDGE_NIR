# Исходные данные H3

Полная учебная база собирается в общие артефакты, в git её нет. Веса старта лежат в `Веса_моделей`.

| Файл | Где лежит | Что это |
|---|---|---|
| `fridge_lab_v3.sqlite` | `Общие_артефакты/данные/` | 500 семей, семя генератора 44, официальный прогон H3 |
| `mlp_hazard_старт.pt` | `Веса_моделей/H3/` | MLP с 14 дневными выходами, старт дообучения |
| `каталог/` | эта папка | справочник продуктов генератора |
| `метрики/полоса_h3b.csv` | эта папка | покрытие и ширина официального теста |
| `метрики/полоса_справка.csv` | эта папка | старые постановки, в порог H3 не входят |

Единица вердикта — строка «семья × продукт». В счёт: продукт брали не меньше трёх раз, следующая покупка внутри 14 дней. Тест: 237 271 строка, походы 1 августа — 16 сентября 2026.

База H3 — полоса ошибок точечного прогноза. Вариант — окно по \(F_d\) на 0,1 и 0,9. Квантили CatBoost в порог не входят.
