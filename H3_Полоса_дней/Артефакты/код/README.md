# Код H3

Четыре шага вердикта. Квантильный CatBoost в эти файлы не входит: он остаётся в `interval_h3.py`.

| Шаг | Файл | Что считает |
|---|---|---|
| 1 | `1_семьи_от_трех_покупок.py` | Какие пары семья × продукт входят в счёт: покупок ≥ 3 |
| 2 | `2_расчет_окна_ошибок.py` | Окно базы: названный день плюс длина ошибки на validation |
| 3 | `3_вероятность_покупки_в_день.py` | Шанс купить в каждый из 14 дней и накопленная F_d |
| 4 | `4_покрытие_и_сужение.py` | Попала ли покупка в окно и насколько окно короче базы |

Полный прогон обучения из этой папки. База — `Общие_артефакты/данные/fridge_lab_v3.sqlite`, старт сети — `Веса_моделей/H3/mlp_hazard_старт.pt`:

```bash
python interval_h3b.py
```

`interval_h3.py` — квантильный CatBoost, в вердикт не входит. `interval_h3a.py` — сеть и F_d, старый коридор покрытия 78–82%. Официальный прогон — `interval_h3b.py`.

Вес 0,25 и сдвиг 0 зафиксированы на июне–июле до теста. Семя AdamW 0. Три эпохи, шаг 1e-4.

Вердикт по уже записанным числам, без обучения:

```bash
python 4_покрытие_и_сужение.py
```

или `python eval_h3.py`. Покрытие не ниже 0,78, окно короче ошибок не меньше чем на 10%.

`purchase_timing.py` — правдоподобие дискретного времени и F_d. Формула лежит в этой папке.
