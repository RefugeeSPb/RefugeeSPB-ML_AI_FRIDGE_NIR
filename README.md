# Гипотезы ML

Три проверки списка и срока покупки на синтетических семьях. Команды ниже запускаются из корня этого репозитория. Базы sqlite в git нет: файл больше лимита GitHub. Короткий пересчёт базы не требует и повторяет таблицу вердикта.

Интерпретатор прогона: Python 3.12.3. Версии пакетов — в `requirements.txt`, сняты с окружения, где стоят CatBoost 1.2.10 и PyTorch 2.14.1+cpu.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## База

Генератор пишет покупки с 1 октября 2025, 365 дней. SEED и число семей задают, какая это база. Файл попадает в `Общие_артефакты/данные/` и в git не входит.

База H1 и официальной строки H2, SEED 42, 200 семей:

```bash
python Общие_артефакты/код/build_db.py --db Общие_артефакты/данные/fridge_lab.sqlite
python Общие_артефакты/код/generate.py --db Общие_артефакты/данные/fridge_lab.sqlite --households 200 --days 365 --seed 42 --start 2025-10-01
```

Повтор H2, SEED 43, 500 семей:

```bash
python Общие_артефакты/код/build_db.py --db Общие_артефакты/данные/fridge_lab_v2.sqlite
python Общие_артефакты/код/generate.py --db Общие_артефакты/данные/fridge_lab_v2.sqlite --households 500 --days 365 --seed 43 --start 2025-10-01
```

H3, SEED 44, 500 семей:

```bash
python Общие_артефакты/код/build_db.py --db Общие_артефакты/данные/fridge_lab_v3.sqlite
python Общие_артефакты/код/generate.py --db Общие_артефакты/данные/fridge_lab_v3.sqlite --households 500 --days 365 --seed 44 --start 2025-10-01
```

`generate.py` очищает таблицы в указанном файле и заполняет их заново.

## H1. Одна модель на всех

SEED модели и бутстрепа — 42. Бутстреп — 2000 повторов. Общая лучше, если низ 95% интервала «общая − личная» строго выше нуля.

Короткий пересчёт читает `H1_Одна_модель_на_всех/Артефакты/данные/метрики/forecast_v2_households.csv` и пишет `H1_Одна_модель_на_всех/Артефакты/результаты/recall10.csv`.

```bash
python H1_Одна_модель_на_всех/Артефакты/код/eval_h1.py
```

Ожидаемая строка csv и печать:

`200 семей SEED 42, 200 семей, личная 0.612, общая 0.625, прирост 0.013, 95% [0.009; 0.018], подтверждена`

Полный прогон заново учит общую модель и личную модель каждой семьи. Он печатает вердикт и csv не переписывает. Интервал в `personal_h1.py` считается через `np.percentile`, в `eval_h1.py` — порядковой статистикой. В таблицу вердикта входит второй способ. Побитово тот же файл весов прогон не обещает. Нужна база семени 42.

```bash
python H1_Одна_модель_на_всех/Артефакты/код/personal_h1.py
```

## H2. Список к походу

Порог прироста Recall@10 — 0,10. SEED модели — 42. На 200 семьях у общей модели 104 дерева, на 500 семьях семени 43 — 265.

Короткий пересчёт модели не учит и базу не читает. Он записывает уже зафиксированную таблицу в `H2_Список_к_походу/Артефакты/результаты/recall10.csv`.

```bash
python H2_Список_к_походу/Артефакты/код/4_сравнение_recall.py
```

Ожидаемые строки:

| База | Походов | Правило | Модель | Прирост | Вердикт |
|---|---:|---:|---:|---:|---|
| 200 семей | 2807 | 0.494 | 0.631 | 0.137 | подтверждена |
| 500 семей, SEED 43 | 6646 | 0.496 | 0.648 | 0.152 | подтверждена |
| Ta Feng, без остатка | 17062 | | | 0.07 | не подтверждена |

Скрипта, который заново считает строку «200 семей» из sqlite и пишет этот csv, в репозитории нет. Полный прогон — повтор на базе семени 43. Он учит CatBoost и печатает гипотезу 0; гипотезы 8 и 2 в таблицу вердикта не входят. Для строки «500 семей» в csv записаны правило 0.496, модель 0.648, прирост 0.152.

```bash
python H2_Список_к_походу/Артефакты/код/check_main_v2.py
```

## H3. Полоса дней

SEED генератора — 44. SEED сети и CatBoost RMSE — 0. Порог, записанный до этой базы: покрытие не ниже 0,78 и окно короче полосы ошибок не меньше чем на 10%.

Короткий пересчёт читает `H3_Полоса_дней/Артефакты/данные/метрики/полоса_h3b.csv` и пишет `H3_Полоса_дней/Артефакты/результаты/полоса.csv`.
