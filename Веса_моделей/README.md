# Веса моделей

Файлы, которые читает прогон. Старт сети H3 — `H3/mlp_hazard_старт.pt`.

## H1 и H2

`H1/catboost_общая_200семей.cbm` и `H2/catboost_общая_200семей.cbm` — один и тот же файл, общая модель CatBoost на 200 семьях.

В файле 104 дерева, шаг 0,08, глубина 6, `l2_leaf_reg` 10, Logloss, SEED 42. Это настройки вердикта на 200 семьях. Модель на 500 семьях, 265 деревьев, на диск не записывалась. Личные модели H1 тоже не записывались: их 200, каждая училась в прогоне и в файл не сохранялась.

Картинка `пример_вклад_признаков.png` снята с этого файла. Самый большой вклад у доли походов, 37%. Дальше давность, остаток и срок.

## H3

`H3/mlp_hazard_старт.pt` — сеть HazardMLP до дообучения. 57 112 чисел: векторы категорий, слои 256 и 128, 14 выходов на дни.

Веса после трёх эпох с весом штрафа 0,25 на диск не записывались. CatBoost RMSE, который называет один день для полосы ошибок, тоже не записан. Файл `catboost_day_v1.cbm` в эту папку не входит: у него другая потеря, другой штраф листа и другое число деревьев.
