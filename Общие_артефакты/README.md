# Общие артефакты

Учебная база синтетических покупок и код, которым она собрана.

| Что | Где |
|---|---|
| Готовая база, 200 семей, семя 42 | `данные/fridge_lab.sqlite` |
| Готовая база, 500 семей, семя 44 | `данные/fridge_lab_v3.sqlite` |
| Код покупок | `код/generate.py` |
| Схема и справочник | `код/schema.sql`, `код/build_db.py`, `код/catalog/` |

База на 200 семей: 19 133 похода, 265 820 строк чека. Походы с 3 октября 2025 по 30 сентября 2026. Год генератора — с 1 октября 2025, 365 дней. Её используют H1 и список к походу.

База на 500 семей, семя 44, собрана уже с записанным порогом полосы дней. На ней подтверждена H3. Повтор списка на 500 семьях, семя 43, — файл `данные/fridge_lab_v2.sqlite`. Готовых sqlite в git нет.

Сборка из корня репозитория, три файла в `данные/`:

```bash
python Общие_артефакты/код/build_db.py --db Общие_артефакты/данные/fridge_lab.sqlite
python Общие_артефакты/код/generate.py --db Общие_артефакты/данные/fridge_lab.sqlite --households 200 --days 365 --seed 42 --start 2025-10-01
```

Семя 43, 500 семей: те же команды с `--db Общие_артефакты/данные/fridge_lab_v2.sqlite --households 500 --seed 43`. Семя 44: `--db Общие_артефакты/данные/fridge_lab_v3.sqlite --households 500 --seed 44`. `generate.py` затирает таблицы в указанном файле.
